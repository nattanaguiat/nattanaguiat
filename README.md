### 🚀 Projects

#### 🏫 [Golf Academy Platform](https://github.com/nattanaguiat/Rio-Pinar-Golf-Academy)
A full-stack web application that manages golf lessons, coaches, and students.  
- Built with **MERN stack**, **JWT authentication**, and **Tailwind CSS**  
- Includes **Admin / Coach / Student** roles with protected routes  
- Integrated **Cloudinary** for media storage and **Express API** for scheduling  
- Deployed with **Render** and **MongoDB Atlas** for reliable backend and database hosting 

#### 🛒 [Go-Go-Grocery](https://github.com/cablej02/go-go-grocery)  
A **PERN stack** application to simulate your grocery list and track your items.  
- Built with **PostgreSQL, Express, React, and Node.js**  
- Organized products by **categories** and quantities dynamically  
- Designed reusable **React components** for adding, editing, and deleting items  
- Deployed with **Render**, ensuring smooth API and database connection
